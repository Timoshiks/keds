# Project Rules

- **Дизайн и разработка интерфейсов**: Работай строго по цепочке: 1. `ui-ux-pro-max` -> 2. `design-taste-frontend` -> 3. `shadcn` -> 4. `minimalist-ui` -> 5. `high-end-visual-design`. Никакого дефолтного shadcn и слопа.
- **Токены и компоненты**: Все компоненты верстать строго по токенам из `DESIGN.md` (`--font-display`, `--font-text`, токены цвета и радиусов). Любое отклонение считать дефектом. При переносе компонентов из `shadcn` забирать только структуру и логику, дефолтные стили `shadcn` полностью вычищать.
