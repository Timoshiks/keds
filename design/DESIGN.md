# DESIGN.md

Дизайн-контракт проекта. Любое отклонение от правил считается дефектом.

---

## 1. Типографика
- **Display Font (Заголовки, цены, статус):** `Unbounded`, `sans-serif` (поддержка кириллицы).
- **Text Font (Основной текст, параметры, кнопки):** `Golos Text`, `sans-serif`.
- **Числа и цены:** строго `font-variant-numeric: tabular-nums` для всех числовых данных (цены, размеры, остатки, таймеры).
- **Иерархия размеров:**
  - H1 / Название экрана: `20px` (weight 700)
  - H2 / Название модели: `15px` (weight 600)
  - Body / Параметры: `13px` (weight 400)
  - Caption / Метки: `11px` (weight 500)
- **Черный список шрифтов:** `Inter`, `Roboto`, `Arial`, `Open Sans`, `Helvetica`.

---

## 2. Цветовые токены (Dark Mode)
Использовать исключительно объявленные токены (запрещены дефолтные классы `zinc-*`, `slate-*`, `gray-*`):

- `--bg-primary`: `#0A0A0A` (основной фон экранов)
- `--bg-surface`: `#141414` (карточки, модалки, плашки без градиентов)
- `--bg-elevated`: `#1C1C1C` (активные чипы, вторичные кнопки)
- `--border-subtle`: `rgba(255, 255, 255, 0.08)` (тонкие разделители 1px)
- `--border-focus`: `rgba(255, 255, 255, 0.24)` (активные поля ввода)
- `--text-primary`: `#F5F5F5` (заголовки, цены)
- `--text-secondary`: `#888888` (размеры, описания, плейсхолдеры)
- `--accent`: `#FF5500` (единственный акцент: кнопка CTA, статус скидки/ошибки)
- `--accent-contrast`: `#FFFFFF` (текст на акцентной кнопке)

---

## 3. Геометрия и сетка
- **Базовый вьюпорт:** `390px` (мобильный контейнер).
- **Радиусы скругления (`border-radius`):**
  - Карточки товаров и нижняя шторка: `12px`
  - Чипы размеров, кнопки, инпуты: `8px`
  - Любые другие произвольные радиусы запрещены.
- **Безопасные отступы Telegram:**
  - `padding-top: max(16px, var(--tg-viewport-safe-area-inset-top, 0px))`
  - `padding-bottom: max(24px, var(--tg-viewport-safe-area-inset-bottom, 0px))`

## 4. Архитектура экранов (по референсам)

### Каталог (`ref_catalog_card.png`)
- 2 колонки, сетка без сплошных заливок фона карточек.
- В верхнем углу карточки: размер и состояние (`EU 42 / New`).
- Крупное фото пары по центру, название модели до 2 строк, цена крупно табличным шрифтом.
- Запрещено: биржевые плашки цен (`Best Price / Last Sold`), синие бейджи таймеров.

### Нижняя навигация (`ref_hotbar.png`)
- Скругленная плавающая плашка над контентом снизу (`bottom: 16px`).
- Фон: `rgba(20, 20, 20, 0.85)` с `backdrop-filter: blur(12px)`.
- 3–4 пункта меню в одну строку с контрастным переключением активного таба.

### Корзина и чекаут (`ref_cart.png`, `ref_order_review.png`, `ref_checkout_form.png`)
- Карточка корзины: текст и кнопка удаления слева, фото пары справа, тонкая нижняя граница.
- Инпуты формы: минималистичные линии с `border-bottom: 1px solid var(--border-subtle)` без тяжелых рамок-оберток.
- Нижний бар чекаута: итоговая сумма + одна акцентная кнопка на всю ширину.

### Меню и выбор адреса (`ref_info_menu.png`, `ref_pickup_location.png`)
- Инфо-списки: вертикальные строки с `chevron-right` и разделителями.
- Подложка карты: интеграция темных тайлов карты, кастомные минималистичные пины ПВЗ.

## 5. Черный список (Anti-Slop Rules)

| Запрещено | Причина |
| :--- | :--- |
| **Мелкий капс с разрядкой** (`PREMIUM SNEAKERS`) | Маркер шаблонного дизайна, создает шум. |
| **Точки-разделители в метаданных** (`New • 42 EU • DS`) | Загромождает карточку; разделять отступами или чипами. |
| **Градиентные подложки на карточках** | Отвлекает от обуви, маскирует пустоту. |
| **Блюр без прокручиваемого слоя под ним** | Неоправданное усложнение рендера. |
| **Слоганы, манифесты и пустые баннеры** | Убираются без потери смысла интерфейса. |
| **Дефолтные компоненты и палитры UI-библиотек** | Убивает индивидуальность продукта под шаблон. |

## 6. Пустые состояния (Empty States)

- Запрещено: оставлять экран только с серым текстом «Пусто» или стоковыми иллюстрациями.
- Обязательно:
  - Короткий лаконичный заголовок (`H2`, шрифт `Unbounded`).
  - Одна четкая кнопка действия (CTA), возвращающая в каталог.
  - Опционально: вывод карусели или чипов быстрых подсказок под кнопкой.
